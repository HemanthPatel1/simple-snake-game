# 🐍 Snake Game

A classic Snake game built with vanilla JavaScript, HTML, and CSS.

## Features

- 🎮 Simple and fun gameplay
- 📊 Score tracking with local storage
- ⏸️ Pause/Resume functionality
- 🎨 Modern UI with gradient background
- 📱 Keyboard controls (Arrow keys)

## How to Play

1. Click "Start Game" to begin
2. Use **Arrow Keys** to move the snake:
   - ⬆️ Up
   - ⬇️ Down
   - ⬅️ Left
   - ➡️ Right
3. Eat the red food squares to grow and earn points
4. Avoid hitting the walls or yourself
5. Try to beat your high score!

## Controls

- **Arrow Keys**: Move snake
- **Start Button**: Begin or restart the game
- **Pause Button**: Pause/resume gameplay

## Features

- High score saved in browser storage
- Smooth gameplay at 100ms per frame
- Collision detection for walls and self
- Score updates when food is eaten

## Installation

1. Clone this repository
2. Open `index.html` in your web browser
3. Start playing!

## Tech Stack

- HTML5
- CSS3 (with gradients and animations)
- JavaScript (ES6+)
- Canvas API for graphics
